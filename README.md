# Лабораторна робота №10: Telegram-бот для тестування знань з Python та ООП

Інтерактивний асинхронний Telegram-бот, розроблений на базі фреймворку **aiogram 3.x**. Бот проводить тестування користувача з 10 випадкових запитань про тонкощі синтаксису Python, принципи ООП, стандартну бібліотеку та типові конструкції коду.

---

## 🚀 Основний функціонал

1. **Команда `/start`**: Запуск нової сесії тестування.
2. **Рандомізація**: При кожному запуску бот відбирає 10 випадкових запитань із загального банку питань та перемішує 4 варіанти відповідей.
3. **Зручний інтерфейс**: Варіанти відповідей подаються у вигляді `Inline`-клавіатури (по 1 кнопці на рядок для зручності на телефонах та десктопах).
4. **Миттєвий зворотний зв'язок**: Одразу після вибору відповіді користувач отримує індикацію (`✅ Правильно!` або `❌ Неправильно!`) з детальним поясненням логіки роботи мови Python.
5. **Фінальна статистика та звіт**:
   * Кількість набраних балів (наприклад, `8 / 10`) та відсоток успішності;
   * Точна дата та час проходження тесту за київським часом;
   * Точна тривалість проходження тесту (у хвилинах та секундах);
   * Повний список запитань з відмітками успішності проходження;
   * Кнопка `🔄 Пройти тест ще раз` для миттєвого нового запуску.

## 🛠 Локальний запуск

### 1. Отримання токена Telegram-бота
1. Відкрийте Telegram і знайдіть офіційного бота [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я бота та його унікальний username (має закінчуватися на `bot`, наприклад: `MyPythonQuizBot`).
4. Скопіюйте отриманий токен (наприклад, `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ`).

### 2. Встановлення та запуск на комп'ютері
```bash
# 1. Створення віртуального оточення
python3 -m venv venv

# 2. Активація віртуального оточення
# На macOS / Linux:
source venv/bin/activate
# На Windows:
venv\Scripts\activate

# 3. Встановлення залежностей
pip install -r requirements.txt

# 4. Створення файлу .env
cp .env.example .env
# Відкрийте файл .env та вставте ваш токен:
# BOT_TOKEN=ваш_токен_тут

# 5. Запуск бота
python main.py
```

## 🌐 Інструкція розгортання на Render (Безкоштовно)

Оскільки наш бот використовує асинхронний **Long Polling**, йому потрібен сервіс типу **Background Worker** (який працює постійно без необхідності приймати вхідні HTTP-запити):

1. **Завантажте проєкт на GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Telegram quiz bot"
   # Створіть новий репозиторій на GitHub та виконайте:
   git branch -M main
   git remote add origin https://github.com/ВАШ_КОРИСТУВАЧ/ВАШ_РЕПОЗИТОРІЙ.git
   git push -u origin main
   ```
2. **Зареєструйтесь / Увійдіть на [Render.com](https://render.com/)**.
3. Натисніть **New +** у правому верхньому кутку та оберіть **Background Worker**.
4. Підключіть ваш GitHub-репозиторій.
5. Заповніть налаштування сервісу:
   * **Name:** `telegram-python-quiz-bot` (або довільна назва);
   * **Region:** Frankfurt (EU) або будь-який найближчий;
   * **Branch:** `main`;
   * **Runtime:** `Python 3`;
   * **Build Command:** `pip install -r requirements.txt`;
   * **Start Command:** `python main.py`.
6. Перейдіть у розділ **Environment Variables** (Змінні середовища):
   * Додайте змінну `BOT_TOKEN` зі значенням вашого токена від `@BotFather`.
7. Натисніть **Create Background Worker**.
8. Render автоматично збере та запустить бота. У вкладці **Logs** ви побачите:
   `Бот успішно запущений і готовий до роботи (Long Polling)!`.
   Тепер бот працює 24/7 у хмарі!

## ☁️ Інструкція розгортання на Heroku

У проєкті вже наявні файли `Procfile` (`worker: python main.py`) та `runtime.txt`:
1. Встановіть **Heroku CLI** та авторизуйтесь: `heroku login`.
2. Створіть додаток: `heroku create your-bot-name`.
3. Встановіть токен бота у конфігурацію:
   ```bash
   heroku config:set BOT_TOKEN="ваш_токен_від_botfather"
   ```
4. Надішліть код у Heroku Git:
   ```bash
   git push heroku main
   ```
5. Активуйте фоновий процес:
   ```bash
   heroku ps:scale worker=1
   ```
